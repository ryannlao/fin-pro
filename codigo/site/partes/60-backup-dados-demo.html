Backup total e controle de versão

Se o computador quebrar amanhã, o sistema inteiro volta com dois cliques

O backup leva tudo o que é preciso para reerguer o Fin Pro em outro computador: dados, comprovantes, configurações, o próprio programa e o histórico de versões. E ele se confere sozinho depois de cada cópia.

O que vai no backup

ParteO que guardaComo é copiada
Bancos e planilhasOs três bancos de dados (boletos, empresas e diesel) e as planilhas ExcelUma cópia por dia, guardando os últimos 30 dias (ajustável)
ArquivosBoletos, comprovantes, cupons do caixa, canhotos, cheques e notasSó o que é novo ou mudou
ConfiguraçõesLembretes, usuários, bots, preços e modelos de importaçãoSempre
Código-fonteO programa inteiroSó o que mudou. O que saiu do sistema sai do backup.
VersõesTodo o histórico de versões num arquivo, e a versão em usoA cada backup
Pacote completoTudo isso num único arquivo .zip, bom para um pen driveToda semana ou todo mês, ou pelo botão. Guarda os últimos 4.
ManifestoA lista de todos os arquivos, com a impressão digital (SHA-256) de cada umA cada backup

Onde e quando

  • Numa pasta do OneDrive, Google Drive ou Dropbox, num pen drive ou num HD externo. O sistema sugere as pastas de nuvem que encontra no computador.
  • Todo dia, no horário escolhido. Se o computador estava desligado, faz assim que abrir.
  • Botões Fazer backup agora, Gerar pacote completo (.zip) e Verificar backup.
  • O menu mostra Backup em dia, atrasado (mais de 2 dias) ou desligado.
  • Além disso, uma cópia diária interna é mantida por 30 dias.

Conferência automática

  • Depois de cada backup, o sistema abre os bancos copiados e confere se estão íntegros.
  • Confere se nenhum comprovante ficou de fora e se o código e as versões estão lá.
  • Verificar backup faz a conferência completa, arquivo por arquivo, comparando a impressão digital.
  • Se algo não bater, o cartão mostra o que foi e a Saúde do sistema fica em Problema.

Restauração

  • Num computador novo, instale o Python, abra a pasta do backup e dê dois cliques em RESTAURAR.bat.
  • Funciona a partir da pasta do backup ou de um pacote .zip.
  • Volta o sistema inteiro: programa, dados, comprovantes, configurações e versões.
  • Se a pasta de destino já tiver dados, ele para em vez de sobrescrever.
  • O restaurador usa só o que já vem com o Python, para rodar antes de instalar qualquer coisa.

Controle de versão

  • Cada versão do programa é guardada com número, data e a lista do que mudou.
  • O cartão Versão do sistema mostra a versão em uso, o histórico e se há alteração ainda não guardada.
  • Dá para comparar duas versões e voltar a qualquer uma.
  • Voltar não apaga nada: o código antigo vira uma versão nova, e os dados não são tocados.
  • As versões guardam só o programa, sem dados, senhas ou tokens.
  • Os testes automáticos rodam antes de cada versão ser guardada.

Saúde do sistema

  • Diagnóstico de banco de dados e planilha, empresas, caixa, diesel, lembretes, backup, recebimento por e-mail e Telegram, gravações pendentes, leitura, espaço em disco e acesso pela rede.
  • Cada item fica Funcionando, Atenção, Problema ou Desligado, com o botão que resolve ao lado.
  • Ações Atualizar a planilha agora e Limpar os logs.
  • O registro de funcionamento tem limite de tamanho e gira sozinho.

Dados e planilha

Banco de dados por baixo, planilha Excel sempre pronta por cima

Você não precisa abandonar o Excel. Os dados ficam em bancos SQLite, com gravação instantânea e segura, e as planilhas são geradas sozinhas poucos segundos depois de cada alteração.

A planilha continua existindo

  • boletos.xlsx com as abas Boletos, Pix, Caixa, Centros de Custo, Resumo e Histórico.
  • fechamentos.xlsx com Empresas, Notas Fiscais, Cheques, Recebimentos e Histórico.
  • diesel.xlsx com máquinas, compras e abastecimentos.
  • Cada lançamento tem o link clicável para o arquivo original.

Aberta no Excel não trava nada

  • Pode deixar a planilha aberta: o sistema continua gravando no banco e atualiza o arquivo quando ele for fechado.
  • Edições feitas no Excel em lançamentos existentes voltam para o sistema.
  • O que foi gravado no sistema nesse meio-tempo não é desfeito.
  • Botões Abrir planilha, Abrir pasta de dados e Baixar cópia.

Onde fica cada coisa

  • Uma pasta dados no computador, com os três bancos, as planilhas e a pasta arquivos com os PDFs e fotos originais.
  • Configurações em arquivos separados: lembretes, usuários, bots, backup, rede e preferências.
  • Cópia diária interna dos bancos e da planilha por 30 dias.
  • Gravação em lote: vários boletos entram numa única gravação.

Versão de demonstração

Veja tudo funcionando com dados de exemplo, sem risco

Dois cliques abrem um Fin Pro completo, cheio de lançamentos fictícios, ao lado do sistema de verdade. Todas as telas desta página foram tiradas dele.

O que vem dentro

  • Boletos pagos, pendentes e atrasados, com juros.
  • Pix, caixa com cupons e sete centros de custo.
  • Três empresas com notas, cheques e recebimentos.
  • Diesel com 5 máquinas, 9 semanas de compras de S10 e comum e os canhotos.
  • Usuários com permissões diferentes, lembretes e resumos ligados.

Seguro para mostrar

  • Nada é enviado para fora: Telegram e e-mail aparecem configurados, mas o envio é bloqueado.
  • Roda em outra porta, ao mesmo tempo que o sistema real.
  • Os dados reais nunca são tocados.
  • A janela mostra o selo Versão de demonstração.

Como abrir

  • Dois cliques em demonstracao.bat.
  • Abre sem senha. Para mostrar as permissões, há três usuários de exemplo: um administrador e dois comuns.
  • demonstracao.bat --refazer monta os dados do zero, com as datas de hoje.
